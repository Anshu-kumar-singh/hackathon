# hackathon
Ward Flow turns 8,000 hospital visits, 2,000 patients, 12 departments and 5,000 tests into a live patient-flow board with alerts, forecasts and a wait-time predictor. Its Dataset X-ray audits the data itself: what drives waits, capacity vs. load, fairness gaps, patient return patterns and 9 contradictions, so every insight is tested, not assumed.
